# Java Multithreaded Alarm System

## Overview
A console-based alarm system developed in Java that allows users to create, view, and stop countdown alarms.

## Features
- Create alarms with custom names and countdown timers.
- Run multiple alarms concurrently using Java threads.
- View alarms that are still running.
- Display a notification when an alarm has 10 seconds remaining.
- Handle invalid timer input and interrupted alarms.

## Technologies
- Java
- Object-Oriented Programming
- Multithreading
- ArrayList
- Exception Handling

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure `Lab10.java` and `Alarm.java` are in the same source directory.
3. Run `Lab10.java`.
4. Follow the menu options in the console.
